# Add slugify

## Why
Demo for blindbuild phase 2: prove a work order goes from the mailbox to a green gate and commits.

## What the user sees
`slugify('Hello, World!')` returns `'hello-world'`.

## Tickets
| Ticket | Scope | Files owned | Depends on |
| --- | --- | --- | --- |
| T1 | slugify function + unit tests | src/slug.mjs, test/slug.test.mjs | — |

## Acceptance
- Lowercases, turns runs of non-alphanumerics into one `-`, trims `-` at both ends.
- `slugify('  Ünïcode & Spaces ')` returns `'unicode-spaces'` (accents removed).
- Empty or symbols-only input returns `''`.
